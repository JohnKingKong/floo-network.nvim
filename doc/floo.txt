1. Introduction                                            *floo-introduction*

floo-network.nvim turns each Neovim tab into an independent fireplace scoped to its
own directory. See the README for the full Floo Network naming rationale
and a keymap table.

==============================================================================
2. Setup                                                          *floo-setup*

>lua
    require("floo").setup({})
<

==============================================================================
3. Config                                                        *floo-config*

See `:help floo-setup` above and README.md for the complete config schema
(`keys`, `dropdown`, `session`, `neo_tree`) with every field documented.

==============================================================================
4. Public API                                                       *floo-api*

require("floo").buf_belongs_to_current_workspace({bufnr})
    Returns whether {bufnr} belongs to the currently active fireplace tab.
    Intended for wiring into bufferline.nvim's `custom_filter` — see
    README.md.
